E-Commerce Sales Analysis Using SQL:

About the Project

This project analyzes e-commerce sales data using SQL Server to understand sales performance, customer behavior, and product performance.

Tools Used

- SQL Server
- SQL Server Management Studio (SSMS)

SQL Concepts

- Joins
- Aggregate Functions
- GROUP BY and HAVING
- CASE Statement
- Subqueries
- CTEs
- Window Functions
- Data Validation

Analysis Performed

- Total Sales Revenue
- City-wise Sales
- Product-wise Sales
- Customer-wise Sales
- Category-wise Sales
- Monthly Sales
- Delivered Revenue
- Product Ranking

Learning Outcome

Learned to analyze sales data, write SQL queries, and validate query results.

Dataset

Sample data created for SQL practice.
